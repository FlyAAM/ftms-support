# r.crew racing
Android application for FTMS-compatible fitness machines with online multiplayer racing support (ble and web).

## Features

### Bluetooth FTMS Support
Connect to compatible fitness machines using Bluetooth FTMS protocol.

Supported device types:
- rowing machines
- indoor bikes
- treadmills
- elliptical trainers

## Online Multiplayer Racing
Create and join real-time online races with other users.

Features:
- live race synchronization
- participant tracking
- race results
- finish times
- spectator mode
- temporary race history

## Workout Programs
Run custom workout sessions and interval programs.

Track:
- distance
- speed
- cadence
- power
- calories
- pace
- heart rate (if supported)

## Real-Time Metrics
The application displays real-time training data from connected FTMS devices.

## Online Race Data
Online race data and results are temporarily stored for synchronization between participants.

Finished and cancelled races are automatically deleted after 24 hours.

## Privacy
The application may use:
- Bluetooth permissions
- Internet connection
- Firebase services for online synchronization

The app does not sell personal data.
